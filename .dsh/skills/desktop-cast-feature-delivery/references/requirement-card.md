# 需求卡模板

复制后填空，写不出「用户点哪里、几秒内看到什么」，说明需求还没拆清。

```markdown
## 目标
用户要完成的一件事：

## 用户旅程
- 谁：
- 在哪（桌面 / 手机在手边或在充电 / 是否同 Wi-Fi）：
- 第一步：
- 之后：
- 结束时看到：

## 成功标准（可观察）
- 操作：
- 时限：
- 可见结果（窗口位置、比例、日志字段、配置落盘等）：

## 非目标
本次明确不做：

## 歧义确认
若原话可能有多种解释，在此列出选项，等用户挑选后再实现：

## 能力边界
- 现成 API 能用：
- 不能用 / 需自研：

## 界面（若涉及）
- 竞品拆解表是否已确认：
- 对照结论：
- 首屏将出现的可交互元素（≤ 5）：
- 为新增控件将删掉的元素：
```
